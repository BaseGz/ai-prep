# 对比实验

> **面试主打区。** 「你怎么切的、为什么」「为什么选这个 embedding」「优化了多少」——
> 这些问题的答案全在这里，而且是带数据的答案。
> 面试前 5 分钟就能打开这四份结论页，这就是你手里的牌。

## 四组实验

| 实验 | 什么时候做 | 要回答的问题 | 产物 |
|---|---|---|---|
| `chunking/` | D17 | 文档怎么切最合适？ | 三种粒度对比 + 结论 |
| `embedding/` | D18 | 中文用哪个 embedding？ | 选型对比 + 结论 |
| `retrieval/` | D20–D21 | 哪种检索方案命中率最高？ | 四组方案对比表 |
| `rag-eval/` | D23 | 整体效果到底行不行？ | 20 题测试集 + 四项指标 |

## 每个实验的固定结构

```
experiments/xxx/
├── README.md      ← 结论页：问题 / 方法 / 数据 / 结论（面试就看这一页）
├── run.py         ← 可重复执行的实验脚本
└── results/       ← 原始记录与图表
```
