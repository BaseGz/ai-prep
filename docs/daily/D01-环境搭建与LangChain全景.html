04 实操 · PyCharm 里七步（约 65 分钟）

全程 GUI，不用命令行（只有 pip install 走 PyCharm 底部「终端」）。

为什么用 3.12，不用 3.13 或 miniconda 的 3.14

版本结论原因
3.12.8用它LangChain 要求 3.10 ≤ Python < 4.0；3.12 的第三方轮子（Chroma / pypdf / 各类 loader，D15 之后要装）最全
3.13 / 3.14.7不用能跑，但后面装向量库和 loader 时更容易遇到没有预编译轮子的包
conda不用PyCharm 项目内 venv 跟着项目走，重装只认 .venv；本项目只有一份环境，用不上 conda 的多环境管理

07 今天最可能踩的两个坑（提前给答案）

现象真实原因怎么修
AuthenticationError / 401 key 填错、前后带空格、或 .env 里给值加了引号（引号被当成 key 的一部分） .env 里顶格写、不加引号：DEEPSEEK_API_KEY=sk-xxx
