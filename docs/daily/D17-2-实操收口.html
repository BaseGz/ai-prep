2d5 · 加分隔符，然后发现它不是万能药

干什么

新建 experiments/chunking/drill/d5.py。这一次不是只改一个参数，而是让两个对象并排比：

doc = Document(page_content=git_data, metadata={"source": "git-guide.txt"})

SEP = ["\n\n", "\n", "。", "，", " "]

for size in (200, 300):
    默认 = RecursiveCharacterTextSplitter(chunk_size=size, chunk_overlap=0)
    加句号 = RecursiveCharacterTextSplitter(chunk_size=size, chunk_overlap=0, separators=SEP)
    for 标签, sp in (("默认", 默认), ("加句号", 加句号)):
        chunks = sp.split_documents([doc])
        # 打印：size / 标签 / 块数 / 长度列表

注意：两个 splitter 都必须建在 for size 里面。建在外面，第二轮的三次输出会和第一轮一模一样——这就是「配置没进对象，调用再多也没用」。

我已实跑的结果

size配置块数各块长度
200默认12[151, 144, 198, 9, 165, 199, 19, 72, 166, 163, 90, 127]
200加句号11[151, 144, 198, 9, 130, 190, 137, 166, 163, 90, 127]
300默认7[297, 209, 165, 291, 247, 174, 127]
300加句号7[297, 209, 256, 201, 247, 174, 127]

这一级要你看清的两件事

① 只有 size=200 有效果。 块数 12 → 11，那几个 19、72 的碎片被合并成了 130 / 190 / 137。因为 200 太小，段落普遍装不下，切分器必须一路降级到「按空格切」——中文没有空格，于是退成逐字硬切，切出碎片。加上 。 之后它有了中文边界可用，碎片就没了。

② size=300 一个块都没少。 块数还是 7，只是中间那两块的位置挪了（165+291 → 256+201）。

这和第二级那条结论是同一件事：分隔符只在「某一片自己就超过上限」的时候才登场。 段落都装得下时，它是装饰品；装不下时，它决定刀落在哪。

4d7 · 换一把尺子，块数立刻变

干什么

新建 d7.py，三件事：

import tiktoken
enc = tiktoken.get_encoding("cl100k_base")

# ① 量一量这份文档：字符多少、token 多少、一个 token 折合几个字
print(len(git_data), len(enc.encode(git_data)))

# ② 换成 token 尺
sp = RecursiveCharacterTextSplitter.from_tiktoken_encoder(
        encoding_name="cl100k_base", chunk_size=256, chunk_overlap=32)
chunks = sp.split_documents([doc])

# ③ 每块实际占多少 token，验证没有一块超 256
print([len(enc.encode(c.page_content)) for c in chunks])

我已实跑的结果

量值说明
字符数（len）1522这就是昨天 chunk_size 一直在量的数
token 数（cl100k）14521 token ≈ 1.05 字
token 尺 256/32 切出9 块每块 token：[224, 248, 8, 161, 237, 79, 212, 193, 109]

同一个 1522 字的文档：字符尺 chunk_size=300 切 7 块；token 尺 chunk_size=256 切 9 块。 块数不是一个「按公式算出来」的数，换尺子就换结果。

为什么这份文档的比值是 1.05，而 chunking.py 里那份 journal 是 1.30： 这份里有 - feat： 这种列表、merge message 这种英文词，英文被切得更碎（一个词常拆成两三个 token）； journal 那份全是中文长句，一个汉字一个 token 居多。所以比值是跟着内容变的，不能背一个固定系数。

还有一个反常的：最后那个 8 块。token 尺也保留短块——上限从来不是下限，这条规律换什么尺子都成立。
