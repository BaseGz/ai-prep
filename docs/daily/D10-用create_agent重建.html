4.1 骨架（这段我在你的 venv 里整段跑过，输出见 4.2）

新建 week2-tools-agent/day10-create-agent/agent_create.py。 关键点：不复制工具 —— 直接从 D9 那个文件 import 过来。同一对工具、同一个模型，才谈得上「对比」。 

"""D10 · 用 create_agent 重建 D9 的 Agent

目标：同一对工具、同一个模型、同一道题。
跑完要能和手写版逐条对齐：7 条消息，两个 tool_calls 挤在同一轮里。
"""
import inspect
import sys
from pathlib import Path

# day09 目录：本文件在 week2-tools-agent/day10-create-agent/ 下，往上一级就是 week2
DAY09 = Path(__file__).resolve().parents[1] / "day09-handwritten-agent"
sys.path.insert(0, str(DAY09))

from langchain.agents import create_agent
from agent_loop import find_order, track_package, model   # 复用 D9 的工具、模型、system prompt 话术

QUESTION = "尾号 8899 名下两单的物流都查一下"


def show(result):
    """把返回的 messages 逐条打出来 —— 这串东西就是「链路」。"""
    msgs = result["messages"]
    print("返回的键：", list(result.keys()))
    print("消息条数：", len(msgs))
    for i, m in enumerate(msgs, 1):
        calls = [c["name"] for c in getattr(m, "tool_calls", []) or []]
        head = str(m.content).replace("\n", " ")[:36]
        print(f"{i}. {type(m).__name__} | 调用 {calls or '-'} | {head}")


def main():
    print("create_agent 的参数：")
    print(inspect.signature(create_agent))
    print()

    agent = create_agent(
        model,
        [find_order, track_package],
        system_prompt="你是一个物流智能查询助手",
        name="logistics_assistant",
    )
    print("返回的对象类型：", type(agent).__name__)

    result = agent.invoke({"messages": [{"role": "user", "content": QUESTION}]})
    show(result)

    print()
    print("终答：")
    print(result["messages"][-1].content)


if __name__ == "__main__":
    main()

4.3 三处要你自己动手的

  1. 把轮数上限压到 3，看它怎么死。把 agent.invoke(...) 改成：

    {"messages": [{"role": "user", "content": QUESTION}]},
    config={"recursion_limit": 3},
)
    我实测的报错原文（你跑出来应该是同一句）： 
    GraphRecursionError: Recursion limit of 3 reached without hitting a stop condition.
You can increase the limit by setting the `recursion_limit` config key.
    这就是你昨天 MAX_ROUNDS = 8 那个 return f"超过最大轮数…" 的框架版 —— 但它不返回一句话，它直接抛异常。记下来：框架的兜底是「炸」，我的兜底是「说一句」。
  2. 只给它一个工具，再问那道题。把 [find_order, track_package] 改成 [find_order]， 跑同一句「尾号 8899 名下两单的物流都查一下」，看模型怎么退让（是老实说查不了，还是硬编一段轨迹）。 这一题我不给预期答案 —— 结果你记下来，正好当 D11「工具不够时 Agent 怎么表现」的底料。
  3. 把「第几轮」打出来，这是框架白送你的东西。加这段： 
    print("—— 用 stream 看它在哪两个节点之间跳 ——")
for chunk in agent.stream(
    {"messages": [{"role": "user", "content": QUESTION}]},
    stream_mode="updates",
):
    for node, payload in chunk.items():
        for m in payload.get("messages", []):
            calls = [c["name"] for c in getattr(m, "tool_calls", []) or []]
            print(f"[{node}] {type(m).__name__} 调用={calls or '-'}")
    我实测的输出（换成「订单 ORD-20261020-003 到哪了？」那道单工具题，轮数更短好观察）： 
    [model] AIMessage 调用=['track_package']
[tools] ToolMessage 调用=-
[model] AIMessage 调用=-
    看到那两个节点名没有：model 和 tools。 你昨天的 for 循环，就是这两个节点在来回跳 —— 框架把它俩画成图了，还每跳一次给你报一次事件。 这是「框架多做了什么」里最直观的一条，手写版要自己加 20 行才做得到。
