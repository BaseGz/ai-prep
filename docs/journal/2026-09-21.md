# 2026-09-21 · D1 环境搭建 + LangChain 全景

## 一句话结论

环境一次配死 —— Python 3.12.8 venv + langchain 1.4.2，后面 34 天不再碰配置。LangChain 的本质是 Model + Harness：模型是零件、框架是装配线，价值在「换供应商只改两行」。另外分清了两套凭据 —— LangSmith 是独立的追踪服务（自己的域名、自己的 key），开关开着但没配 key 只会被 401 刷屏。

## 今天的坑

现象：跑 `hello_model.py` 时控制台刷 LangSmith 401
（`api.smith.langchain.com/runs/multipart` Unauthorized），但模型回复本身是正常的。
我以为：401 是 DeepSeek 的 key 失效、或者 base_url 配错。
实际：报错来自 **LangSmith 追踪服务**（另一个域名、另一套凭据）。`.env` 里
`LANGSMITH_TRACING=true` 但 `LANGSMITH_API_KEY` 为空 —— 开关开着却没钥匙，就一直被拒。
怎么定位到的：看报错里的**域名** —— 是 `smith.langchain.com` 而不是 `deepseek.com`。
已修：`.env` / `.env.example` 的 `LANGSMITH_TRACING` 改成 `false`，重跑验证输出干净。
（完整四段式已抄进 `errors/index.md`）
