# 每日日志

文件名：`YYYY-MM-DD.md`（当天日期）。每天 10 分钟，只写三件事。

## 模板

```markdown
# 2026-XX-XX · D__ （当天主题）

## 一句话结论
（不是「今天学了 Tools」，而是「Tools 的本质是模型输出 JSON 意图、代码负责执行，所以模型本身没权限」）

## 今天的坑
现象：
我以为：
实际：
怎么定位到的：

## 明天第一件事
```

## 为什么只写三行

日志写多了你会放弃。三行是能坚持 35 天的量，而且这三行恰好就是面试时最值钱的部分。
坑的部分，顺手也往 `errors/index.md` 抄一份。
