方向 A · 多模态素材整理 Agent（推荐）
思路
拖一批照片/视频进去 → 视觉模型自动打标签、生成文案 → 支持自然语言语义检索。技术栈：LangChain 编排 + 视觉模型 + 向量库。踩中「多模态」+「内部工具」+「设计工程」三个加分点，影石是做相机的，面试官一看就懂价值。
方向 B · 内部知识库 Agent
思路
说明书 / FAQ / 客服工单做成 RAG，再挂工具调用（查工单状态、生成回复草稿），加 interrupt 做人工确认。经典但扎实，能体现你对「AI 不能瞎执行」这件事有工程意识。

技术栈：Python 还是 JS/TS

B 站上的中文教程 95% 是 Python 版。如果你走前端 / 全栈路线，建议「概念看 Python 教程，代码用 LangChain.js 重写一遍」——这样既拿到了最好的中文讲解，又保住了自己的技术栈，而且影石 JD 明确提到了浏览器插件、Figma 插件、Design Engineering，JS/TS 在这条线上是加分位。

选教程的避坑清单

  • 看到这些名字直接换教程：LLMChain、initialize_agent、AgentExecutor、ConversationBufferMemory、SequentialChain。这是 LangChain 0.x 的老 API，中文教程里大量存在。现在要认准 create_agent 和 LangGraph。用这一条筛，能帮你省掉一大半无效学习时间。
  • 别把「绑定一个第三方服务」当成学习内容。LangChain 有几百个 loader / integration，用到再查文档，不要逐个看。
  • 不要只刷视频不动手。JD 写着「面试请准备演示」，看完一章就立刻写一遍，哪怕只有 20 行。
  • 模型别用太贵的。练手用 DeepSeek / 通义 / 智谱，都走 OpenAI 兼容协议，便宜且不用折腾网络；Embedding 用 bge-large-zh 或通义 embedding，中文效果明显好过 OpenAI 的。
  • MCP 和 RAG、Agent 别贪多。JD 是「三选一」，把 LangChain（Agent + Tool）和 RAG 吃透，MCP 了解 + 一个小 Demo 就够。
  • 项目最后一定要有「省了多少时间」的数字。100 张图人工整理 40 分钟 → 工具 2 分钟，做成一张表 + 截图。这条比技术本身更打动面试官。

面试讲项目的固定结构

问题是什么 → 我为什么这么选（舍弃了什么）→ 结果数据 → 踩过的坑。
尤其「舍弃了什么」和「踩过的坑」这两段，是面试官判断你有没有真做过的最快方式。准备了演示 Demo 的同学，这两段一定要提前演练。
