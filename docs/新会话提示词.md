# 新会话开场提示词

在 WorkBuddy 新建的项目聊天里，**第一句话**粘下面这段即可接上全部上下文。

---

MCP 任意一项。目前已经定好 35 天路线（2026-09-21 起，每天 3 小时，四个重点日 D9 手写 Agent 循环 /

## 精简版（已经聊过几轮、只想快速接上时用）

```text
继续我的影石实习准备项目：先读 D:\insta360-ai-prep\docs\context.md，再读 docs\progress.md 和
journal/ 里最新的日志。我用 PyCharm 提交、要精确到章节、中文交付结论先行。今天做 D__。
```

---

## 使用说明

- 每次开新聊天**只发一次**，之后就不用再重复背景了。
- 结尾的 `D__（日期 ____）` 记得填，例如 `D1（2026-09-21）`。
- 如果新聊天读不到 D 盘文件（权限或路径问题），就把 `docs\context.md` 全文直接贴进去，效果一样。
- 这份文件里不写死的部分（进度、结论）都在 `context.md`，改了那边这里不用动。
