# 报错档案

> **这是整个仓库最值钱的文件。** 面试问「踩过什么坑」，你不会记得三个月前的细节，但这个文件记得。
> 按「现象 / 我以为 / 实际 / 怎么定位到的」记，四段缺一不可 —— 缺了「我以为」，就只是照着报错改代码，没什么可讲的。

## 模板

```markdown
## D__ · 一句话描述问题

**现象**：
（原始报错信息，别概括，原样贴）

**我以为**：
（你当时的错误判断 —— 这段最能体现你是想过的）

**实际**：
（真实原因）

**怎么定位到的**：
（打印了什么、查了什么文档、二分了什么）

**结论**：
（一句可复用的经验，面试时直接念这句）
```
