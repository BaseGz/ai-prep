# 提效度量

> **这是整个计划里最对应 JD 的一天（D34）。**
> JD 原文：「有数据意识：做工具时会想『怎么证明它省了多少时间』」。

## 要测什么

| 指标 | 怎么测 |
|---|---|
| 单次耗时对比 | 人工做 100 条计时 vs 工具做同样 100 条计时 |
| 准确率差异 | 同样 100 条，两边各对多少 |
| 折算收益 | 按每周用 5 次、每月 4 周折算成小时 |
| 成本 | token 花费，和节省的时间对比 |

## 原始记录

放 `raw/`。**必须是真实计时数据**，不要估。

## 结论

（一句话，这就是面试时最有力的输出。目标长这样：
「100 条人工 40 分钟 → 工具 2 分钟，每周用 5 次能省 3 小时」）
