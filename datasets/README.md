## 这是什么

RAG 练习用的真实语料。**从 D15 起所有练习都用它**，D29 之后它直接变成项目的数据集。
面试时这套语料就是我的项目背景。

## 规则

1. 原始大文件放 `datasets/raw/`，已 gitignore，**不入库**
2. 清洗后的数据（小体积）可以入库
3. 每个数据集在这里写清：来源 / 规模 / 怎么拿到 / 字段含义
