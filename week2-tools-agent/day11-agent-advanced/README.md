## 三、今天提交什么

在 PyCharm 里分 **2 次** 提交。Ctrl + K 打开提交窗口后，**记得取消勾选不属于本次提交的文件**。

### 第 1 条

```text
fix(day11): 单个工具抛异常导致 Agent 循环整体中断

现象：工具报错直接冒到顶层，后续轮次全没了
原因：执行工具那一步没有 try/except
做法：把异常信息包成字符串，当 ToolMessage 回传即可
结论：工具失败不该中断循环，而应把错误当结果交给模型自己判断
```
