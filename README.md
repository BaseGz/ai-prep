# insta360-ai-prep

影石（Insta360）AI 应用开发实习 · 35 天准备仓库

## 30 秒看懂这个仓库

- **效果数据** → `project/benchmarks/`
- **我踩过的坑** → `errors/index.md`
- **演示视频** → 待 D35 补链接

## 这个仓库是什么

目标岗位的四条硬要求：能独立完成小型全栈原型、有自己动手做过的 AI 小项目、
面试能当场演示、有数据意识。所以这个仓库**不是学习笔记，是证据**。

## 怎么读

| 目录 | 是什么 |
|---|---|
| `docs/plan/` | 35 天计划表、资源导航、面试手册、Git 规范（4 个 HTML，用浏览器打开） |
| `docs/journal/` | 每天一条：今天的结论 + 今天的坑 |
| `docs/decisions.md` | 技术选型：选了什么、为什么不选另一个 |
| `docs/progress.md` | 35 天进度表，每天打勾 |
| `errors/index.md` | 报错档案，按「现象 / 我以为 / 实际 / 怎么定位」记 —— 面试最值钱的素材 |
| `experiments/` | 四组对比实验（切分 / Embedding 选型 / 检索方案 / RAG 评估），面试主打 |
| `week1-basics/` … `week4-adv/` | 每天一个练习目录，里面的 README 写着当天要学什么、提交什么 |
| `project/` | 第 5 周的完整作品，面试 80% 的时间花在这 |
| `datasets/` | 语料（原始大文件不入库，只提交清单与来源说明） |

## 三条铁律

1. 当天代码当天跑通，当天提交
2. 每 7 天不上新课，只做产出
3. 从 D15 起，所有练习都用我自己的语料 —— 面试时它就是我的项目
